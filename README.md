# ELEVOS — Football Management Simulation

독립적인 가상 구단과 선수들을 육성하는 웹 축구 감독 시뮬레이션입니다.

## 현재 구현 범위 (2026-11-23)
- 8개국, 12개 가상 리그, 144개 가상 구단. 각 리그는 **12팀 / 22라운드**의 프로토타입 규모
- 잉글랜드, 이탈리아, 프랑스, 독일은 1·2부 리그와 상하위 두 팀 승격·강등
- 스페인, 포르투갈, 네덜란드, 벨기에는 1부 리그
- 각 구단 23명, 총 3,312명 가상 선수
- 가상 선수 이름, 나이, 포지션, 18개 세부 능력치, 성장 포인트, 잠재력
- 선수 프로필 보강: 국적, 신장, 체중, 주발, 계약 만료 연도. 이전 저장본에 해당 필드가 없으면 ID 기반 기본값 자동 채움
- 선수별 레벨과 경험치 및 세부 스탯 +1 육성
- 4-3-3, 4-2-3-1, 4-4-2, 3-5-2, 3-4-3 포메이션
- 선발 11명 직접 변경, 포지션 적합도와 선발 능력치가 경기 시뮬레이션에 반영됨
- 리그 순위, 득실차, 라운드 대진표, 시즌 운영, 기본 이적시장
- 브라우저 localStorage 저장

## 2026-11-23: 파운드 게임머니
- 상단 보유 금액은 모든 페이지에서 £ 단위로 표시하고 천 단위 쉼표를 적용합니다.
- 새 플레이어의 시작 금액은 게임머니 £1,000입니다. 기존 저장본에는 영속 저장되는 파운드 지갑 필드를 처음 추가할 때에만 £1,000을 배정하며 재접속 시 재지급하지 않습니다.
- 경기 보상: 승리 £80, 무승부 £45, 패배 £25. 기본 경험치는 별도 지급됩니다.

- 이적료는 선수 종합 능력치에 기반한 파운드 가격으로 재조정했습니다. 선수 영입 시 지갑에서 차감됩니다.
- 파운드는 현실 화폐가 아닌 게임 내부 재화입니다. 재정 및 이적시장 밸런스는 초기 테스트 후 재조정합니다.

## 2026-11-24: 이벤트 기반 2D 경기·부상·교체·육성 개선
- 중계는 출전 중인 선수 이름을 중심으로 패스, 슈팅, 파울, 득점, 경고·퇴장을 서술합니다. AI 팀 역시 실제 경기장에 배치된 선수 ID에서 이벤트 주체를 선택합니다.

- 득점 연출: 잠정 GOAL 약 2초 → VAR CHECK 약 2초 → 인정 또는 오프사이드 취소 판정. PK도 선언 2초 후 판정됩니다. VAR 취소 득점은 결과와 순위표에 반영되지 않습니다.
- 전반 종료 시 3초 간 하프타임을 표시한 뒤 SECOND HALF 킥오프. 90분 정규 시간이 차면 진행바는 100%, 추가시간은 90+N 형식으로 별도 표시합니다.
