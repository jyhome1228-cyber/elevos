# ELEVOS — Football Management Simulation

독립적인 가상 구단과 선수들을 육성하는 웹 축구 감독 시뮬레이션입니다.

## 현재 구현 범위 (2026-11-23)
- 8개국, 12개 가상 리그, 144개 가상 구단. 각 리그는 **12팀 / 22라운드**의 프로토타입 규모
- 잉글랜드, 이탈리아, 프랑스, 독일은 1·2부 리그와 상하위 두 팀 승격·강등
- 스페인, 포르투갈, 네덜란드, 벨기에는 1부 리그
- 각 구단 23명, 총 3,312명 가상 선수
- 가상 선수 이름, 나이, 포지션, 18개 세부 능력치, 성장 포인트, 잠재력
- 선수 프로필 보강: 국적, 신장, 체중, 주발, 계약 만료 연도. 이전 저장본에 해당 필드가 없으면 ID 기반 기본값 자동 채움
- 선수별 레벨과 경험치 및 세부 스탯 +1 육성
- 4-3-3, 4-2-3-1, 4-4-2, 3-5-2, 3-4-3 포메이션
- 선발 11명 직접 변경, 포지션 적합도와 선발 능력치가 경기 시뮬레이션에 반영됨
- 리그 순위, 득실차, 라운드 대진표, 시즌 운영, 기본 이적시장
- 브라우저 localStorage 저장

- 선수단: 사진 기반 선수 카드 목록과 우측 상세 성장 패널을 제공. 기존 능력치 상한 120 및 육성 포인트 유지.
- 이적시장: 사진 카드, 이름 검색, 포지션 필터, 영입 UI로 재구성.
- 144개 가상 구단의 한국어 표시명과 3,312명 선수 이름 생성 조합(40개 이름 + 40개 성)을 한국어로 제공.
- 원문 이름은 nameEn에 보존하며 표시 언어 선택을 localStorage에 기억. 헤더의 표시 언어 버튼으로 현재 구단·선수 이름만 영문/한글 전환 가능. 전체 UI 영문화는 향후 과제.
- 기존 구단/선수 ID, 능력치, 진행 기록은 유지. 첫 구단 ID=0의 화면 이동 오류 수정.
- 초기 구현은 여전히 정적 HTML 내부에 로직이 포함된 프로토타입. 별도 파일/모듈 분리는 향후 리팩터링 과제.

## 2026-11-23: 파운드 게임머니
- 상단 보유 금액은 모든 페이지에서 £ 단위로 표시하고 천 단위 쉼표를 적용합니다.
- 새 플레이어의 시작 금액은 게임머니 £1,000입니다. 기존 저장본에는 영속 저장되는 파운드 지갑 필드를 처음 추가할 때에만 £1,000을 배정하며 재접속 시 재지급하지 않습니다.
- 경기 보상: 승리 £80, 무승부 £45, 패배 £25. 기본 경험치는 별도 지급됩니다.
- 3장 보상 선택의 게임머니 카드는 추가 £100입니다. 정원 초과 유망주 카드 대체 보상도 £100입니다.
- 이적료는 선수 종합 능력치에 기반한 파운드 가격으로 재조정했습니다. 선수 영입 시 지갑에서 차감됩니다.
- 파운드는 현실 화폐가 아닌 게임 내부 재화입니다. 재정 및 이적시장 밸런스는 초기 테스트 후 재조정합니다.

## 2026-11-23: 드래그 전술 및 1분 단위 시뮬레이션
- 전술 화면의 경기장 위 선발 선수 11명 마커를 마우스로 드래그하여 선발 선수끼리 위치를 교체
- 우측 후보 선수도 경기장 마커에 드롭하여 주전으로 교체. 기존 셀렉트와 자동 선발 기능은 유지
- 경기 준비 화면에서 '시뮬레이션 시작'을 누르면 0분부터 90분까지 게임 속 시간이 1분씩 진행. 자동 진행과 +1분 진행 버튼 제공
- 매분 중계 메시지, 공격/슈팅/득점 이벤트 및 점수 업데이트. 현재 경기장 선수는 배치 마커이며 개별 선수의 물리 이동 AI는 미구현
- 전반 45분에 하프타임 자동 일시정지, 후반 시작 후 90분 경기 종료
- 최종 결과는 기존 리그 승점·경기 기록·XP·파운드·3장 카드 보상 로직에 한 번만 반영
- 진행 중 시뮬레이션 상태를 로컬 저장하여 새로고침 후 이어서 진행 가능
- 현재는 기본 확률 기반 이벤트 엔진. 선수별 패스/슈팅 등 18개 스탯을 세밀하게 반영하는 전술적 이벤트 엔진과 실시간 선수 움직임은 차기 개발 대상

## 경기 중 지시 및 보상 화면 개편 (2026-11-24)
- 경기 중 감독이 공격 강화/균형 유지/수비 강화를 선택 가능. 선택 즉시 이후 이벤트 확률 계산에 사용
- 경기 중 교체 선수/OUT 선수를 선택하여 최대 5명 교체. 드롭다운을 조작하면 자동으로 일시정지되며 계속 진행으로 재개
- 진행 중 교체/전술 지시/참가 선수 목록과 주요 득점·경고·퇴장 이벤트를 저장
- **경기 스코어의 단일 기준은 시뮬레이션에서 기록한 homeGoals/awayGoals.** 90분 후 그 값을 바꾸지 않고 최종 결과·리그 일정·승점에 사용
- 경기 종료 화면을 FULL TIME 스코어보드, 기본 파운드·경험치 보상, MVP 및 주요 이벤트 내역으로 개편
- 3장 중 1장 보상 카드를 이미지형 인터랙션으로 정리하고, 중복 수령 방지. 결과·보상·메뉴에 선형 SVG 아이콘 적용
- 현재 경기 결과의 골·경고·퇴장 기록은 시뮬레이션에서 발생한 이벤트에 근거하며, 세부 수치 기반 실시간 이동·퇴장에 따른 수적 열세·카드 누적 출전 정지 등은 추후 구현 대상
