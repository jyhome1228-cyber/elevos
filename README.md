# ELEVOS

가상의 구단과 선수를 기반으로 한 브라우저 축구 감독 시뮬레이션 초기 프로토타입.

## 포함 기능
- 8개 국가, 12개 리그, 144개 구단 (리그별 12개)
- 잉글랜드, 이탈리아, 프랑스, 독일은 1·2부 리그 및 시즌 종료 시 자동 승격/강등
- 스페인, 포르투갈, 네덜란드, 벨기에는 1부 리그
- 각 구단 23명, 총 3,312명 가상 선수 자동 생성
- 선수별 포지션, 나이, 레벨, 경험치, 능력치, 잠재력
- 경기 완료 시 경험치 부여 / 레벨업 시 +3 스탯 포인트 / 능력치 +1 직접 배분
- 4-3-3, 4-2-3-1, 4-4-2 전술 및 경기 성향·압박 강도
- 정규 리그 22라운드 (12개 구단 홈/원정)
- 간단한 경기 시뮬레이션, 순위, 이적시장, 가상 이적 자금
- 브라우저 localStorage 자동 저장

## 실행 방법
별도 빌드나 개발 서버 없이 index.html 파일을 브라우저에서 실행할 수 있습니다.
GitHub Pages를 사용하려면 저장소 Settings > Pages > Deploy from a branch > main / (root)를 선택해야 합니다.

## 중요한 한계
- 초기 프로토타입이며 2D 애니메이션 경기 화면은 아직 구현되지 않았습니다.
- 경기 엔진은 브라우저에서 실행되는 단순 확률 기반입니다.
- 저장 데이터는 이용 중인 브라우저의 localStorage에만 보관됩니다. Firebase 연동과 계정 로그인은 미구현입니다.
- 구단 및 선수 이름은 독자적인 예시이며, 기존 제3자 상표와의 충돌 여부는 별도 검토가 필요합니다.
- 상용화 전 시뮬레이션 밸런스, 선수단 인원 제한, 보안, 지속성, 일정 관리 및 브라우저 테스트가 필요합니다.
- 리그 이름은 가상의 명칭입니다. 통계 연동은 API 라이선스 확인 이후에만 추가합니다.
